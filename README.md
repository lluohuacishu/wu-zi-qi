# 五子棋 AI

基于 Python 和 Pygame 开发的五子棋对战程序，支持人机对战、本地双人对战、局域网对战、禁手规则、AI 难度选择和局面评估控制台。

## 功能特性

- 图形界面：使用 `pygame` 绘制棋盘、棋子、提示信息和难度菜单。
- 人机对战：内置五子棋 AI，支持玩家选择先手或后手。
- 双人对战：支持本地双人轮流落子。
- 局域网对战：支持一台电脑创建主机，另一台电脑输入主机 IP 加入。
- AI 算法：使用 Minimax、Alpha-Beta 剪枝和 VCF 算杀逻辑。
- 性能优化：使用 `numpy` 和 `numba` 加速局面评估。
- 禁手规则：可在开局前切换黑棋长连、三三、四四禁手判断。
- 评估控制台：显示当前局面评分和历史手顺得分。

## 运行环境

- Python 3.13
- `pygame`
- `numpy`
- `numba`

安装依赖：

```bash
pip install -r requirements.txt
```

运行程序：

```bash
python main.py
```

## 操作说明

- 左键：落子
- 右键：本地双人/人机模式下悔棋
- `A`：开局前切换玩家先后手
- `B`：人机模式下请求 AI 辅助落子
- `C`：非局域网模式下显示或隐藏评估控制台
- `D`：开局前开启或关闭禁手规则
- `E`：开局前切换人机/双人模式
- `F`：人机模式下打开 AI 难度菜单
- `N`：开局前创建局域网主机，界面会显示 `IP:端口#房间码`
- `J`：开局前加入局域网主机，输入 `主机IP#6位房间码`，加入方执主机的另一方
- `A`：局域网主机等待对方加入时切换自己执黑或执白
- `D`：局域网主机等待对方加入时开启或关闭本局禁手规则
- `R`：局域网模式下请求/同意重开，双方都按 `R` 后才会重开
- `Esc`：局域网模式下退出联机，切换为本地双人

局域网对战默认使用 TCP 端口 `50007`。两台电脑需要在同一局域网内，并使用同一版新的 `五子棋.exe`；如果 Windows 防火墙弹窗，请允许本程序访问专用网络。房间码用于避免同一局域网内其他设备误连。进入局域网模式后不支持悔棋、AI 辅助和评估控制台。对局结束后双方都按 `R` 重开时会自动交换黑白。一方退出或关闭程序后，另一方会收到提示并切换为本地双人。

## 打包说明

项目使用 PyInstaller 打包，配置文件为 `五子棋.spec`。程序启动时会自动检测用户系统中可用的中文字体；如果没有匹配字体，会回退到 Pygame 默认字体。

打包命令：

```bash
pyinstaller 五子棋.spec
```

打包产物默认生成在 `dist/` 目录。
