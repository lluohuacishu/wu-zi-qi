## 五子棋人工智能

这是一个基于 Python 开发的五子棋对战程序，不仅拥有图形界面，还内置了一个菜菜的博弈 AI。本项目作为课程大作业开发，记录了从基础逻辑到性能优化的完整过程。

## 核心特性

- **图形界面**：基于 `pygame` 开发，界面简洁，支持鼠标交互。
- **核心算法**：采用 **Minimax (极大极小值算法)** 配合 **Alpha-Beta 剪枝**进行博弈树搜索。
- **性能引擎**：采用 `numpy` 矩阵运算，并引入 `numba` JIT 即时编译技术，将核心的棋盘评估速度提升到 C 语言级别。
- **进阶算杀**：内置 VCF 专属算杀模块，具备深度的防守与绝杀嗅觉。
- **开发者控制台**：按 `C` 键可展开侧边栏，实时查看当前局面的 AI 评分与历史手顺得分。

## 环境依赖

本程序使用了以下 Python 库：
`pygame`、`numpy`、`numba`
